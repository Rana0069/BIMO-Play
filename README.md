## ⚡ Overview

**BIMO CLI** is a powerful command-line tool built to inject custom modifications, UI themes, and rich JavaScript extensions directly into the official Spotify desktop client. 

Whether you want a minimalist AMOLED dark theme, lyric widgets, enhanced shuffle algorithms, or full custom apps inside Spotify, BIMO gives you complete power over your music environment.

Supports: **Windows**, **macOS**, and **Linux**.

---

## ✨ Features

- 🎨 **Complete UI Theming:** Change every color across the Spotify interface with ease.
- 🖌️ **Direct CSS Injection:** Inject your own custom stylesheets to tweak or completely overhaul Spotify's layout.
- 🧩 **Powerful Extensions:** Add custom JS extensions to manipulate the UI, enhance audio queue management, auto-skip videos, and more.
- 📱 **Custom Apps:** Embed dedicated mini-applications right inside Spotify's navigation sidebar.
- 🔀 **Smart Features Included:**
  - **Shuffle+**: Zero-bias Fisher–Yates shuffle algorithm.
  - **Popup Lyrics**: Live, synced lyrics display.
  - **Trash Bin**: Instantly blacklist songs or artists you never want to hear again.
  - **Bookmarks & Loops**: Save track timestamps and loop favorite sections.

---

## 🚀 Quick Start

### Basic Commands

```bash
# Apply modifications and launch Spotify
bimo apply

# Backup current Spotify client files
bimo backup apply

# Revert Spotify to its vanilla, untouched state
bimo restore

# Inspect current configuration
bimo config
```
